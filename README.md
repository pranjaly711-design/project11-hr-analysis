# project11-hr-analysis
HR Analytics - Predict Employee Attrition
📌 Project Overview

This project focuses on analyzing employee attrition patterns and identifying the key factors that influence employee turnover. Using HR Analytics data, I performed data cleaning, exploratory data analysis (EDA), machine learning modeling, and Power BI dashboard visualization to generate actionable business insights.

🎯 Objective

To understand the major causes of employee resignation and predict future attrition using analytics and machine learning techniques.

🔍 Key Insights
People with low salary are leaving more.
Employees working overtime show higher attrition.
Employees without promotions are more likely to leave.
Recently joined employees have higher turnover rates.
Lower job-level employees demonstrate increased attrition.

📈 Results

Developed predictive models for employee attrition.
Evaluated model performance using Accuracy Score and Confusion Matrix.
Identified key business factors affecting employee retention.

🚀 Conclusion

The analysis revealed that salary, overtime, promotions, and employee experience play a significant role in attrition. Organizations can use these insights to improve employee retention and workforce planning.
